# Lisbon Chair Shop

A responsive landing page for a fictional furniture shop that sells ergonomic chairs. It has a hero section, a feature list, a bestsellers section with product cards, and customer testimonials.

**Live demo:** [chairs-for-sale.netlify.app](https://chairs-for-sale.netlify.app/)

![Lisbon Chair Shop](https://raw.githubusercontent.com/pokurumohanendra/My-Portfolio/main/public/projects/lisbon-chair-shop.jpg)

## Features

- Hero section with a clear call to action
- "What makes our chairs special" feature list
- Bestselling chairs as product cards
- Customer testimonials
- Responsive layout

## Tech stack

HTML5 and CSS3. No build step or dependencies.

## Getting started

Open `index.html` in a browser, or serve the folder with any static server:

```bash
npx serve .
```

## Project structure

```
index.html
style.css
img/       images used on the page
```

Built as a learning project to practise page structure, CSS layout and styling.
